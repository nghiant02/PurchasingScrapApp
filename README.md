# Purchasing Scrap App

## Introduction
Purchasing Scrap App is a Java-based application designed to manage scrap purchasing processes efficiently. This application provides functionalities to manage tasks, staff, and scrap posts.

## Features
- Task assignment and management.
- Staff management.
- Scrap post management.

## Installation
To run the application, ensure you have Java installed on your machine. Clone the repository and navigate to the project directory.

```bash
git clone https://github.com/nghiant02/PurchasingScrapApp.git
cd PurchasingScrapApp
```

## Usage
To run the application, compile the Java files and execute the main class.

```bash
javac -d bin src/main/java/com/example/Main.java
java -cp bin com.example.Main
```
